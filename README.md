# calculadora

## Sobre o projeto

Este projeto foi desenvolvido em Python e tem como objetivo realizar a conversão de números entre diferentes bases numéricas.

O programa permite converter números entre as bases:

- Binária (base 2)
- Octal (base 8)
- Decimal (base 10)
- Hexadecimal (base 16)
- Outras bases (de 2 até 36)

## Funcionalidades

- Escolher a base de origem.
- Escolher a base de destino.
- Inserir o número que deseja converter.
- Validar se o número é permitido na base escolhida.
- Realizar conversões com números positivos e negativos.
- Repetir as conversões sem precisar reiniciar o programa.
- Tratar entradas inválidas utilizando try-except.

## Como executar

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto.
3. Execute o arquivo Python no terminal ou em uma IDE.
4. Escolha as bases e informe o número que deseja converter.

O objetivo do projeto é colocar em prática os conhecimentos de lógica de programação, funções, estruturas de repetição, condicionais e tratamento de erros em Python.
